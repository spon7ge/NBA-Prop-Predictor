EXPERIMENT LOG
==============

Fill a block when you change data, split, features, or model family.
Holdout numbers only count if the holdout was still blind at decision time.

How to add an entry
-------------------
1. State what you believed would improve (one sentence).
2. Note split + whether holdout was still untouched.
3. Primary metric + at least one counter.
4. Decision: ship / reject / needs redo — with why.

Copy the blank template below for each new experiment.
